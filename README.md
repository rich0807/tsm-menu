# TSM MENU

一個基於 **Fabric v0.119.2+1.21.4** 的 Minecraft 模組，提供TSM(台灣學生麥塊)玩家一個 **自訂快捷選單**，方便快速使用伺服器功能。  

---

## 🎯 功能需求  

### 🔑 自訂按鍵
- 預設按鍵：`I`(可於案件設定中調整)  
- 功能：打開 **主選單**

---

### 🏠 主選單
包含以下按鈕：

- **傳送** → 進入「傳送子選單」  
- **公會** → 進入「公會子選單」  
- **飛行** → 進入「飛行子選單」  
- **等級**  
- **任務**  
- **垃圾桶**  
- **背包**  
- **終界箱**  
- **拍賣**  
- **合成**  

---

### 📌 傳送子選單
- **鑰匙**  
- **出生點**  
- **小鎮**  
- **蘑菇島**  
- **上個地點**  
- **home點**  
- **返回主選單**  

---

### 🏰 公會子選單
- **公會資訊**  
- **公會箱子**  
- **公會聊天開關**  
- **聯盟聊天開關**  
- **返回主選單**  

---

### ✈️ 飛行子選單
- **飛行商店**  
- **飛行開關**  
- **返回主選單**  

---

## ⚙️ 開發資訊
- **模組名稱**：tsm menu  
- **開發平台**：Fabric  
- **支援版本**：Minecraft `1.21.4`  
- **模組版本**：`v1.0.0`

## 🚀 使用方式
1. 將模組放入 `mods` 資料夾  
2. 進入遊戲後按下 `I` 鍵開啟 **主選單**  
3. 點擊功能按鈕即可快速使用伺服器功能
